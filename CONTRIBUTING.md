# Contributing to LoopGolem

Use English for engineering communication, preserve Windows/Linux compatibility, keep user-visible strings localized, and do not introduce credential scraping, automatic paid API fallback or automatic credit purchases.

## Build

```bash
dotnet restore LoopGolem.sln
dotnet build LoopGolem.sln -c Release
```

Pull requests should explain what changed, why it changed and how it was verified.

By contributing, you agree that your contribution is licensed under Apache-2.0.
