# LoopGolem

**Dê um objetivo. Ele continua trabalhando.**

LoopGolem é um orquestrador open source de tarefas autônomas para Windows e Linux. Ele transforma um objetivo de alto nível em trabalho persistente, retomável e consciente de custo, executado por agentes em pequenas tarefas.

> O projeto está em desenvolvimento inicial; arquitetura e interfaces ainda podem mudar.

## Core principles

- Persistent and resumable missions
- Cost-conscious model routing
- Pause and resume around quota limits
- Deterministic verification before additional AI usage
- Official provider authentication; no password storage
- Code and technical documentation in English
