# LoopGolem

**یک هدف بدهید. به کار ادامه می‌دهد.**

LoopGolem یک هماهنگ‌کننده متن‌باز برای وظایف خودکار در Windows وLinux است. یک هدف سطح بالا را به کارهای کوچک، ماندگار، قابل‌ازسرگیری و کم‌هزینه برای عامل‌ها تبدیل می‌کند.

> پروژه در مرحله آغازین توسعه است و معماری و رابط‌ها ممکن است تغییر کنند.

## Core principles

- Persistent and resumable missions
- Cost-conscious model routing
- Pause and resume around quota limits
- Deterministic verification before additional AI usage
- Official provider authentication; no password storage
- Code and technical documentation in English
