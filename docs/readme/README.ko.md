# LoopGolem

**목표를 주면 계속 작업합니다.**

LoopGolem은 Windows와 Linux용 오픈 소스 자율 작업 오케스트레이터입니다. 높은 수준의 목표를 지속 가능하고 재개 가능하며 비용을 고려한 작은 에이전트 작업으로 나눕니다.

> 현재 초기 개발 단계이며 아키텍처와 인터페이스는 변경될 수 있습니다.

## Core principles

- Persistent and resumable missions
- Cost-conscious model routing
- Pause and resume around quota limits
- Deterministic verification before additional AI usage
- Official provider authentication; no password storage
- Code and technical documentation in English
