# LoopGolem

**Dale un objetivo. Sigue trabajando.**

LoopGolem es un orquestador open source de tareas autónomas para Windows y Linux. Convierte un objetivo de alto nivel en trabajo persistente, reanudable y consciente del costo, ejecutado por agentes en pequeñas tareas.

> El proyecto está en desarrollo inicial; la arquitectura y las interfaces aún pueden cambiar.

## Core principles

- Persistent and resumable missions
- Cost-conscious model routing
- Pause and resume around quota limits
- Deterministic verification before additional AI usage
- Official provider authentication; no password storage
- Code and technical documentation in English
