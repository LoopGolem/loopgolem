# LoopGolem

**Donnez-lui un objectif. Il continue à travailler.**

LoopGolem est un orchestrateur open source de tâches autonomes pour Windows et Linux. Il transforme un objectif de haut niveau en travail persistant, reprenable et attentif aux coûts, exécuté par des agents sous forme de petites tâches.

> Le projet est au début de son développement ; l'architecture et les interfaces peuvent encore évoluer.

## Core principles

- Persistent and resumable missions
- Cost-conscious model routing
- Pause and resume around quota limits
- Deterministic verification before additional AI usage
- Official provider authentication; no password storage
- Code and technical documentation in English
