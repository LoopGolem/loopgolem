# LoopGolem

**Dagli un obiettivo. Continua a lavorare.**

LoopGolem è un orchestratore open source di attività autonome per Windows e Linux. Trasforma un obiettivo di alto livello in lavoro persistente, riprendibile e attento ai costi, eseguito dagli agenti in piccoli compiti.

> Il progetto è nelle prime fasi di sviluppo; architettura e interfacce possono ancora cambiare.

## Core principles

- Persistent and resumable missions
- Cost-conscious model routing
- Pause and resume around quota limits
- Deterministic verification before additional AI usage
- Official provider authentication; no password storage
- Code and technical documentation in English
