# LoopGolem

**أعطه هدفًا. وسيواصل العمل.**

LoopGolem هو منسق مفتوح المصدر للمهام الذاتية على Windows وLinux. يحول الهدف عالي المستوى إلى عمل مستمر قابل للاستئناف وواعٍ بالتكلفة، تنفذه الوكلاء على شكل مهام صغيرة.

> المشروع في مرحلة تطوير مبكرة وقد تتغير البنية والواجهات.

## Core principles

- Persistent and resumable missions
- Cost-conscious model routing
- Pause and resume around quota limits
- Deterministic verification before additional AI usage
- Official provider authentication; no password storage
- Code and technical documentation in English
