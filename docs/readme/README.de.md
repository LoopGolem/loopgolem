# LoopGolem

**Gib ein Ziel vor. Es arbeitet weiter.**

LoopGolem ist ein quelloffener Orchestrator für autonome Aufgaben unter Windows und Linux. Ein übergeordnetes Ziel wird in persistente, fortsetzbare und kostenbewusste Kleinarbeit für Agenten zerlegt.

> Das Projekt befindet sich in einer frühen Entwicklungsphase; Architektur und Schnittstellen können sich noch ändern.

## Core principles

- Persistent and resumable missions
- Cost-conscious model routing
- Pause and resume around quota limits
- Deterministic verification before additional AI usage
- Official provider authentication; no password storage
- Code and technical documentation in English
