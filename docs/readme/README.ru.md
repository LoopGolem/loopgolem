# LoopGolem

**Дайте ему цель. Он продолжит работать.**

LoopGolem — открытый оркестратор автономных задач для Windows и Linux. Он превращает высокоуровневую цель в устойчивую, возобновляемую и экономную последовательность небольших задач для агентов.

> Проект находится на ранней стадии разработки; архитектура и интерфейсы ещё могут измениться.

## Core principles

- Persistent and resumable missions
- Cost-conscious model routing
- Pause and resume around quota limits
- Deterministic verification before additional AI usage
- Official provider authentication; no password storage
- Code and technical documentation in English
