# Localization

English is canonical for user-facing copy and all engineering material.

Launch locales: en-US, pt-BR, es, de, it, fr, he, ar, fa, ja, ko, ru.

Hebrew (he), Arabic (ar) and Persian (fa) are RTL. User-visible application strings belong in ResX resources; missing translations fall back to English. README.md is canonical and translated README files are human-facing convenience documents.
