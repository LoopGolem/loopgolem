# Product principles

- Durable mission state, not disposable chat state.
- Cheap execution preferred over fast execution when no human is waiting.
- Deterministic tools perform deterministic checks.
- Included-plan quota exhaustion pauses and resumes work.
- Paid API usage is never a silent fallback.
- Credits are never purchased automatically.
- Stronger models are escalation tools, not default workers.
- Users can pause, inspect and resume missions.
- UI is multilingual; engineering language is English.
- Open-source distribution and commercial reuse are first-class requirements.
