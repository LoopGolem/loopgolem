# Security policy

LoopGolem executes agent-directed work on user machines, so security boundaries are product requirements.

Never commit or post passwords, API keys, OAuth tokens, cookies or other secrets. Provider credentials must not be exposed to prompts. Execution permissions must stay within explicit policy.

Please use GitHub private vulnerability reporting / Security Advisories when available. Do not publish exploit details or credentials in a public issue.

Supported-version guarantees will be defined before the first stable release.
